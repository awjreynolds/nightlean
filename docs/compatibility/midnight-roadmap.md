# Midnight roadmap and the pinned target

Checked on 2026-11-19 against Midnight's public roadmap and Ledger 9 release notes. Noctium's development qualification still uses Ledger 9.1.0.1 and ZKIR 3.2.1. Midnight reports Ledger 9 on its public networks and newer 9.1.0.2 client packages as of November 17. The development receipts apply to the pinned localnet. [Midnight roadmap](https://midnight.network/roadmap) · [Ledger 9 release notes](https://docs.midnight.network/relnotes/ledger-9)

The roadmap's offer-file work concerns private trades. Noctium's composition transport already exchanges public call material between independent witness owners. Trade semantics and wallet settlement need separate qualification. [Independent composition](../development/native-call-claims.md) · [Midnight roadmap](https://midnight.network/roadmap)

Proposed MIP-0020 uses an existing native proving primitive to regenerate a prover key from exact ZKIR and the deployed verifier key. No consensus change is required. A pinned Rust experiment reproduced the retained K10 token `balanceOf` prover key byte for byte. It independently regenerated the expected verifier with the pinned SRS, matched the retained verifier, and rejected the `pendingOf` verifier despite matching K and row counts. Then `setup_pk` generated the exact 1,066,185-byte key from 32,040 bytes of ZKIR and the 1,593-byte verifier. The experiment used retained localnet files. [MIP-0020](https://github.com/midnightntwrk/midnight-improvement-proposals/blob/main/mips/mip-0020-prover-key-regeneration.md) · [Token benchmark](../development/oz-compile-performance.md)

Noctium's Rust SDK now loads bundles distributed without the prover key. The loader matches the selected operation's installed verifier from host-supplied contract state and authenticates the regenerated key against the release manifest. The K9 private-claim bundle dropped from 477,325 to 29,585 bytes before compression. The Rust test generated and verified the private-claim proof using the regenerated key and attached the proof to its native intent. Host state retrieval, browser and mobile integration remain open.
