# Recipient-bound disclosure on Ledger 9

`DirectedDisclosure.Inbox` seals one public Jubjub recipient key at deployment. A publisher supplies an eight-bit private value and a private nonzero scalar. `publish` requires the supplied recipient to equal the sealed key. The circuit releases the two ElGamal points `rG` and `valueG + rP`. Those points replace the corresponding public cells. The receiver key and transaction metadata remain public. [Lean contract](../../examples/DirectedDisclosure.lean)

The recipient checks that its secret key derives the sealed public key, subtracts its shared point from the ciphertext and looks up the resulting point in the 256-element message range. Confidentiality relies on the prime-order Jubjub group, the decisional Diffie–Hellman assumption and a fresh, secret, uniformly sampled nonzero scalar for every encryption. The circuit checks nonzero and relies on the publisher for freshness. The inbox permits any sender to replace the last ciphertext and uses an application-specific layout. [ElGamal construction](https://crypto.stanford.edu/~dabo/cryptobook/BonehShoup_0_4.pdf)

The example targets Ledger 9 and ZKIR 3.2.1. Midnight's roadmap schedules its own directed-disclosure feature for Q1 2027. Standard wire format and key-policy compatibility remain open. [Midnight roadmap](https://midnight.network/roadmap)

## Lean source proof

`successful_publish` reasons about the entrypoint generated by the actual Lean contract. For the inbox's three-cell layout, it proves that a successful execution uses the stored receiver key, evaluates the two encryption expressions, exposes exactly those points as its circuit outputs, and replaces only the ciphertext cells. `encrypt_outputs` identifies both expressions in any successful evaluation of the source circuit. The proof checks the source evaluator with its curve operations supplied through `EvalContext`. The kernel reports `propext`, `Classical.choice` and `Quot.sound` across the two theorems. Cryptographic confidentiality and full compiler preservation have separate trust assumptions. [Source proof](../../examples/DirectedDisclosureProof.lean)

## Localnet result

The native ZKIR tool sized the circuit at K12 and 2,138 rows. The Rust SDK generated and verified the proof, finalized deployment at height 30201 and finalized `publish` at height 30204. The test decoded the finalized ledger state and recovered the synthetic value 42 with the intended key. It rejected an unrelated decryption key, a changed recipient during call preparation and a zero nonce. A separate Lean compile rejected a type-correct plaintext write to a public cell and emitted no artifacts. ## Reproduce

Build the Lean compiler and compile `examples/DirectedDisclosure.lean` with `--emit ledger --target profiles/midnight-ledger-9-zkir-3.2.1-target.json`. Use the pinned ZKIR tool to generate the K12 keys. Assemble the `DirectedDisclosure.Inbox.publish` bundle with those keys, the source, compiler artifacts, C ABI, pinned native tool identity and public localnet ledger parameters. [Bundle workflow](portable-artifacts.md#build-and-use)

Check the two theorems against the same source.

```sh
mkdir -p build/experiments/disclosure-proof
lake env lean -R examples -o build/experiments/disclosure-proof/DirectedDisclosure.olean \
  examples/DirectedDisclosure.lean
LEAN_PATH="$PWD/build/experiments/disclosure-proof${LEAN_PATH:+:$LEAN_PATH}" \
  lake env lean -R examples examples/DirectedDisclosureProof.lean
```

To exercise the cleartext rejection, add `cell clear : UInt 8`, initialize it to zero and add `write clear := value` to `publish`. Compile the mutated source to a fresh destination and look for the diagnostic identifying the undisclosed private `value`.

Run the native test against the funded development genesis at loopback port 19944. Use the authenticated manifest digest, a parameter cache with the pinned K12 and development DUST materials, and the public synthetic seed in the test. [Start the development chain](../../scripts/localnet/README.md)

```sh
NOCTIUM_DISCLOSURE_BUNDLE=/path/to/bundle \
NOCTIUM_DISCLOSURE_MANIFEST_SHA256=TRUSTED_MANIFEST_DIGEST \
NOCTIUM_DISCLOSURE_PARAMETER_CACHE=/path/to/parameters \
cargo +1.100.0 test --manifest-path runtime/Cargo.toml --locked \
  --no-default-features --features zkir-321,localnet \
  --test directed_disclosure -- --ignored --nocapture
```
