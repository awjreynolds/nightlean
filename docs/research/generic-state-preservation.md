## Remaining qualification before closing issue 66

The public soundness and completeness roles both compile and audit to the three standard Lean axioms. The completeness proof constructs the actual SSA assignment and decoded circuit satisfaction from a successful original source call; no premise supplies desired relation satisfaction, VM success, or a successor. Astra review requested that the public result expose its already-proved source read assignment and tape; the strengthened local two-role export is 90,414,390 bytes. The earlier 90,187,213-byte export passed fresh data-only default-kernel replay in 20.95 seconds with 3,410,018,304 bytes peak child RSS; that measurement is historical and does not qualify the strengthened role. The dedicated `GenericStateExportAudit` checks fixed role types and transitive axiom closure, with a 128 MiB export cap and 300-second process timeout. The issue-specific audit driver passed a local positive replay and 11 negative cases for role substitution, forged axioms, wrong pin, file type/size, malformed prefix, and model mismatch. Independent reviewed model pinning and the corresponding immutable-source rerun remain open. The mixed-schema and computed-output source/native checker mutations are complete finite checks; they do not substitute for that pin.

The raw JSON parser, pretty printer, file IO, native Rust implementation, and target resource limits remain separate evidence boundaries. The plan-tree certificate is exact at the Lean compiler's pure constructor. It does not alone authenticate an external file. Generic readMap and guarded control need later backend support.

The fixed PrivateClaim historical source and certificate identities are separate from this generic work. Do not relabel fresh proof evidence as the old artifact authority.
